# My Divine Aesthetics

Luxury, 3D React website for **My Divine Aesthetics** — sacred self-care, medical aesthetics, and wellness.

## Stack

- React 18 + Vite
- Tailwind CSS (custom luxury palette)
- Framer Motion (page + scroll animations)
- React Three Fiber + drei (3D hero scene)
- Lucide React (icons)
- React Router (Home, About, Services, Gallery, Blog, Contact)

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Structure

```
src/
  components/
    3d/           # React Three Fiber scenes
    layout/       # Navbar, Footer, Logo, ScrollToTop
    sections/     # Hero, FeaturedServices, Testimonials, etc.
  pages/          # Home, About, Services, Gallery, Blog, Contact
  data/           # services, testimonials, blog
  App.jsx
  main.jsx
  index.css
```
